# PLAN-0013：使用 HTMLKit 重新设计排行榜与图表

| 状态 | 完成时间 |
|---|---|
| 已完成 | 2026-09-05 |

## 问题与最终结果

旧排行榜只把前五和后五压成昵称字典，同名会覆盖，中段本人没有进入图片；两种图都依赖 Pillow。用户确认新的左右布局后，已将排行榜和个人历史注入图正式接入 HTMLKit，应用层、数据库、查询快照和游戏规则保持不变。

排行榜左侧为头像、昵称和真实名次，右侧为竖向柱状图。展示前五、后五以及中段本人左右各一位，最多十三人且不重复；本人名字、名次与柱体同步高亮。正蓝负粉、统一线性刻度、正数不加加号、刻度朝内，仅保留纵轴和零线。六个汉字可完整单行展示，超长昵称按实际字体测量后最多两行。量级悬殊时保留真实比例，接受小柱被压缩。

个人历史图左侧为头像、昵称、累计量和日期明细，右侧为每日注入量折线。横轴保持真实日期间隔，缺失日期不补零；沿用现有长历史规则，超过十八条的明细只列最早、最近各九条，折线使用全部记录，至少两天才附图。两种图均使用确认后的简洁样式，不增加外围框、姓名缩写或装饰。

## 关键改动

| 位置 | 最终改动 |
|---|---|
| `infra/chart_layout.py` | 按真实名次选择用户；以明确的 `RankEntry` 承载展示身份、数值和本人标记；纯函数计算柱体、刻度和日期折线几何。 |
| `infra/chart_renderer.py`、`infra/templates/` | 统一 HTMLKit 渲染、严格模板字段校验与自动转义；用 CSS 渐变线段实现折线，不使用 SVG、Canvas 或浏览器。模板随 wheel 打包。 |
| `bot/handlers/records.py` | 先选择实际展示名次，再从 Uninfo 获取名称和头像，不以昵称作为唯一键。 |
| `bot/handlers/query.py` | 为本人或被查询者读取资料；历史记录和累计量都直接使用应用层同一次查询结果，不增加数据库查询或结算。 |
| 插件入口与依赖 | 显式 require HTMLKit/LocalStore，固定 HTMLKit rc5，直接声明 Jinja2；删除 Pillow 直接依赖、旧图片实现和不再使用的 SIMYOU.TTF，不分发字体文件。 |
| 资源生命周期 | 字体发现与初始化交给 HTMLKit，插件不生成或修改共享 Fontconfig。Config 中的默认字体为 Noto Sans CJK SC，正文、数字和昵称测量统一使用，可用 IMPART_FONT_FAMILY 覆盖。原生出图并发最多两次、头像下载最多四次，头像限定 HTTP(S)、大小和超时，无头像时不创建 HTTP 客户端，渲染本身禁止外部图片/CSS 加载。 |
| 清理与检查入口 | 独立 `examples/` 原型已迁出；临时源码、安装依赖和旧字体备份保存在工作树外，PNG 预览仍留在本地忽略的 scratch 中。pytest/Ruff 配置保持原样，根目录默认命令可正常运行。布局不再重复计算累计量或保存无消费者的字宽调试字段。 |

用户已确认 D-001：出图失败保留原排名或状态/合计文字，追加“图表生成失败”，不维护 Pillow fallback。只捕获绘图异常；业务查询、身份和消息发送异常仍维持既有边界。资料查询失败时昵称退回用户 ID，头像获取失败时留空。

D-002 在此次接入中沿用旧插件的最早、最近各九条明细，不采用原型的无限增高列表，也不缩减参与折线与累计量的历史数据。

## 部署边界

默认使用 Noto Sans CJK SC；字体需由部署环境提供，不再依赖旧包内字体。未安装目标字体时由 HTMLKit 匹配可用替代，精简 Linux 环境需准备中文字体。当前没有真实 Adapter 在线发送验收，仍以既有 OneBot V11 Handler 回归与实际图片渲染作为验收边界。
