# PLAN-0015：重设 XNN 互动并增加双向贴贴结算

| 状态 | 完成时间 |
|---|---|
| 已完成 | 2026-09-05 |

## 问题与最终结果

基于 `feature@c416eaf` 实施，替代旧的 XNN 随机反制及仅被透才能触发雌堕的规则。普通男性为 `length >= 5`，XNN 为 `0 < length < 5`，女性为负值。双方 XNN 优先贴贴；其他错误动作由对方按合法动作反制一次，不再抽反制随机数。

| 发起者 → 目标 | 请求透／日 | 请求榨 |
|---|---|---|
| 普通男性 → 普通男性 | 正常透 | 被反透 |
| 普通男性 → XNN | 正常透 | 被反榨 |
| 普通男性 → 女性 | 正常透 | 被反榨 |
| XNN → 普通男性 | 被反透 | 正常榨 |
| XNN → XNN | 贴贴 | 贴贴 |
| XNN → 女性 | 正常透 | 被反榨 |
| 女性 → 普通男性 | 被反透 | 正常榨 |
| 女性 → XNN | 被反透 | 正常榨 |
| 女性 → 女性 | 被反榨 | 正常榨 |

XNN 实际透或反透为1～10ml，贴贴两个方向独立1～10ml，其余互动继续1～100ml，包括女性榨 XNN。数量保留三位小数，按发起者输出→目标输出的顺序抽取，随后只抽一次1～20秒耗时。普通互动仍为数量→耗时。

实际接收者累计对方输出；例如 A/B 原总量100/200，本次分别输出7/3，则 A/B 新总量103/207。所有实际收量且最终仍是 XNN 的成员独立判定雌堕，涵盖主动榨、反榨与贴贴。继续使用 `clamp((total - 200) / 800, 0, 1)` 与长度减5cm；警告仅在 `previous_total <= 200 < total` 且本次未转换时产生。双方事件互不取消、不保存通知标记。

## 关键改动与并发边界

| 位置 | 最终改动 |
|---|---|
| `impart/core.py::resolve_interaction()` | 确定性三状态规则与内部 CUDDLE；一至两笔不可变 InteractionTransfer 固定 source、recipient、fluid、max_volume |
| `impart/app.py::prepare_interaction()`、`begin_interaction()` | 初始化发起者使用共享锁；锁外选人，开始阶段在锁内复核发起者冷却、初始化目标、批量读取状态并记录冷却 |
| `impart/app.py::complete_interaction()` | 按冻结流向生成数量，最终锁内读齐接收者最新状态，按发起者→目标顺序独立生成转换随机值；结果按实际接收成员关联 |
| `infra/data_manager.py::get_user_states()` | 一次读取参与者状态，避免开始或最终快照按人分开读取 |
| `infra/data_manager.py::settle_interaction_volumes()` | 替换单人入口；只捕获一次日期，以一个事务提交全部收量与转换，任一失败共同回滚 |
| `bot/handlers/interaction.py` | 复用资料查询获得菜单昵称；支持贴贴报告与双方事件，正确区分输出量、接收总量和转换主体；开始阶段冷却拒绝不再继续动画或结算 |

开始与最终阶段共享 PK、成长、夺舍使用的同一个 application 状态锁；成员目录、资料查询、消息发送及两秒动画均不持锁。开始后不重解析动作、数量档位或液体，最终状态只决定谁能参与转换：离开 XNN 的人只累计，进入 XNN 的人可以转换。第一人的转换不会影响第二人的资格。

非零冷却下，同一发起者并发开始只能通过一条；只用既有发起者冷却，不占用目标、不增加运行中禁用，零冷却允许连续开始。事务失败共同回滚，消息失败不撤销或重放已提交结果，既有冷却不因失败回滚。

## 接入和文案

- 不增加命令、alias、schema、依赖、多进程锁或旧版本兼容层；群友首 At、管理/群主忽略 At、自目标拒绝及资料失败兜底不变。发起者首次创建即返回，缺失目标以10cm初始化后继续。
- 双 XNN 自动选人提示沿用 main：`{botname}发现你俩都是xnn喵~现在咱将{发起者}\n送给{目标}色色！`。显式 At 仍不额外发送前置提示。
- 贴贴报告按用户定稿使用「蹭蹭贴贴」「分别挤出了」，先写发起者/目标的输出量，再写各自收到后的累计量。保留原单张目标头像和 UniMessage 结构。
- 普通透/榨报告格式保持不变；个人事件在完整报告后按发起者→目标追加，同一人的转换覆盖风险警告。
- 转换原因分别为「在{实际行动者}的猛烈攻势下」「在{转换者}的主动索求下」「在一阵缠绵后」，结尾采用「变成了女孩子喵！」。来源在等待期间换形态也不改本次液体名称；每人事件只选一次部位名称。
- 公开帮助仍隐藏概率阈值；无新挑战、胜率、成长奖励或转换之外的长度变化。
