# PLAN-0019：三阶终阶挑战

| 状态 | 完成时间 |
|---|---|
| 已完成 | 2026-09-05 |

## 问题与最终结果

在[PLAN-0018](PLAN-0018-second-tier-challenge.md)的阶级接入基础上启用三阶。当前最高阶段为正值“牛々の神”、负值“深淵の主”；达到三阶仍可继续成长，没有自动新增第四阶或长度上限。与二阶一并实施，未提交Git。

## 已实现规则

| 项目 | 三阶规则 |
|---|---|
| 进入/保级 | 1000cm绝对长度 |
| 完成 | 1050cm，包含等号且保留超出数值 |
| 失败/掉阶罚退 | 朝零方向50cm一次，正常保留二阶 |
| 挑战胜率 | 当前胜率×0.7一次，退出乘10/7恢复 |
| 持有后的基础变动 | ×4 |
| 持有后的PK上限 | 四目标，可少于上限，共用一次胜负 |

- 挑战三阶期间仍持有二阶，用×3、最多三目标；通关当局保留原资格，下次才×4、四目标。三阶掉阶当局仍使用×4及已选四目标，下次回到×3、三目标；最终锁内资格不足时整场拒绝，不裁剪目标。
- 基础量0.6、三阶对四个无阶目标：赢时发起者+4.8、各目标-0.6；输时发起者-9.6、各目标+0.3。只选一人赢+1.2、输-2.4。每人的胜率、挑战后处理及固定罚退仅一次；最多五人全量原子写回。
- 挑战失败在基础结算落到999cm时再罚至949cm，保留二阶且恢复三阶减益；已持有三阶者同样从999罚至949并降二阶，但没有挑战减益就不恢复胜率。已持有三阶处于1000～1050仍保级，不重新挑战。
- 成长倍率覆盖自成长、被目标成长及PK收益/损失，不作用于固定罚退、冷却、胜率、毫升、雌堕或夺舍平分。普通玩法保持原世界。

## 夺舍与导入边界

- 负值三阶挑战者仍可夺舍，退出旧挑战免罚并解除减益；例如-1020cm、tier2夺舍900cm→自身450cm、tier2。
- 平分仍以保级门槛直接授阶，允许绕过目标世界试炼：-2500cm、tier3夺舍2000cm、tier3→双方1000cm、tier3；不再进入正值三阶挑战。
- 1500cm、tier3目标平分后750cm，再按原三阶罚退50→700cm、tier2；发起者750cm、tier2且免罚。
- 上游导入使用完成目标：1000≤绝对长度<1050为tier2、三阶挑战中并应用0.7；≥1050直接tier3。旧0.8减益按导入适配解除，不补罚长度或补播。
- 夺舍直授与导入取得的新能力在后续操作正常生效，但不伪造普通通关事件。

## 文案

各阶试炼名保持一致：“登神长阶／深渊试炼”，结算使用“登神挑战／深渊挑战”。原文句式、对应数值替换及已确认的正负掉阶模板详见PLAN-0018。掉阶只展示失去的旧称号与原罚退鼓励句，不新增退回称号/倍率说明。

正常三阶通关后独立At，正值开头“你感到一股神性的力量正涌入体内...”，负值“你感到深渊的禁忌力量正涌入体内...”，再分别提示：

> 你的任何基础长度/深度变动将提升至4倍！
> PK现在最多可以指定四个目标了！

长度/深度按世界选取；不重复解锁夺舍。多人不同阶级通关依次通知实际成员，发送不持锁且失败不回滚/重放结算。
