# PLAN-0003：增加负值状态自我成长

| 状态 | 完成时间 |
|---|---|
| 已完成 | 2026-09-03 |

## 问题与最终结果

原实现把 `length <= 0` 只作为查询和反透状态，没有对应的自我成长入口；打胶还会让负值向零移动。本计划完成时，`打胶/开导` 只服务 `length > 0`，新增 `开扣/挖矿` 服务 `length <= 0` 并写入负增量，所有负值自我成长和查询使用绝对值与“深度”；该阶段暂不触发 25/30 挑战，后续由 PLAN-0006 补齐。

打胶、开扣、嗦、查询和 PK 同时采用统一首次初始化边界：场景与命令语义有效后，为本次涉及的所有缺失用户创建长度 `10.0`、胜率 `0.5` 的状态并立即回复；该次不执行全局惩罚、游戏结算随机、冷却、挑战或其他结算。创建结果携带实际 Ref，因此单人、目标和双方文案不会误报已存在用户。

## 关键改动

| 模块或路径 | 最终改动 |
|---|---|
| `impart/core.py` | 增加长度/深度成长模式、世界边界和带符号增量纯规则；`0` 属于深度模式 |
| `impart/app.py` | 四个现有用例复用缺失用户初始化；自我成长按模式编排，世界检查早于冷却，深度路径跳过挑战 |
| `bot/matchers.py`、`bot/handlers/game.py` | 用一个 Alconna 命令头映射把打胶/开导、开扣/挖矿直接解析为 `GrowthMode`，由单一 matcher 和 Handler 处理；同时统一初始化文案，并为负值查询输出“小学”和绝对深度 |
| `config.py`、`bot/handlers/shared.py`、`bot/handlers/records.py` | 删除 `jj_variable` 配置；牛牛名称硬编码为 `牛子/牛牛/newnew`，负值部位固定为 `小学` |
| `README.md`、插件元数据、architecture | 公开新增命令、首次初始化和当前正负世界边界 |
